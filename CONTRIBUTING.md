# Contributing

Thanks for considering a contribution to Africa SaaS Starter.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Keep changes small and documented.
4. Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
5. Open a pull request explaining the problem and the chosen solution.

## Principles

- Prefer simple, portable abstractions over vendor lock-in.
- Keep authorization enforced at the data layer when possible.
- Do not commit credentials, customer data or proprietary integrations.
- Add documentation for new environment variables and public APIs.
